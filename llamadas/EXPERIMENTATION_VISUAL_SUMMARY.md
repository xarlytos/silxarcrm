## HOW IT WORKS: 3-LAYER SYSTEM

```
┌──────────────────────────────────────────────────────────────────┐
│                    EXPERIMENTATION FRAMEWORK                      │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  LAYER 1: A/B TESTING (Structured experiments)                  │
│  ├─ Argument tests:  "ROI arg" vs "Automation arg"             │
│  ├─ Offer tests:     "$1900" vs "$1500"                        │
│  ├─ Action tests:    "Demo" vs "Followup"                      │
│  └─ Decision:        Statistically rigorous (p < 0.05)         │
│                                                                  │
│  LAYER 2: MULTI-ARMED BANDITS (Continuous learning)            │
│  ├─ Thompson Sampling:  Arguments learn from every call         │
│  ├─ ε-Greedy:          Actions learn from feedback              │
│  ├─ Contextual:        By industry, size, lead score           │
│  └─ Automated:         No manual tuning needed                  │
│                                                                  │
│  LAYER 3: SAFETY (Prevent bad decisions)                        │
│  ├─ Hypothesis validation (must be falsable)                    │
│  ├─ Min sample size (typically 400/variant)                     │
│  ├─ Early stopping (if treatment is BAD)                        │
│  ├─ Rollout stages (5% → 25% → 100%)                           │
│  └─ Monitoring (hourly health checks)                           │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

## REVENUE MATH (Simplified)

```
BASELINE (Current):
┌─────────────────────────────────────────────────────┐
│ 200 calls/day × 30 = 6,000 calls/month             │
│ 6,000 × 25% close rate = 1,500 closed deals        │
│ 1,500 × $4,500 avg deal = $6.75M/month             │
└─────────────────────────────────────────────────────┘

AFTER 6 MONTHS (With Experimentation):
┌─────────────────────────────────────────────────────┐
│ Same volume: 6,000 calls/month                      │
│ IMPROVED close rate: 31.8% (+6.8%, compounded)     │
│ IMPROVED deal value: $4,750 (+5.5%)                │
│                                                     │
│ Closed deals: 6,000 × 31.8% = 1,908 deals         │
│ Revenue: 1,908 × $4,750 = $9.06M/month            │
│                                                     │
│ Incremental: $9.06M - $6.75M = $2.31M/month       │
│ 6-month cumulative: $2.31M × 6 ÷ 2 = $3.88M       │
│ (÷2 because ramp is gradual, not day 1)            │
└─────────────────────────────────────────────────────┘

MINUS INVESTMENT:
$3.88M - $210K = $3.67M NET PROFIT
$3.67M ÷ $210K = 17.5x ROI
```
