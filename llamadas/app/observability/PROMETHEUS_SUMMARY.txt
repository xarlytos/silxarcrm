QUICK START (5 MINUTOS):
───────────────────────

1. Instalar:
   pip install prometheus_client

2. En main.py:
   from app.observability.prometheus_integration import (
       setup_prometheus_endpoint,
       add_prometheus_middleware,
   )

   app = FastAPI()
   add_prometheus_middleware(app, agent_type="sales", model_name="gemini-2.0")
   setup_prometheus_endpoint(app)

3. Verificar:
   curl http://localhost:8000/metrics

4. Integración automática:
   ✓ Todos los endpoints miden latencias automáticamente
   ✓ Llamadas API se cuentan automáticamente
   ✓ Registra métricas en formato Prometheus

# Opción 1: Middleware automático (recomendado)
# Mide todos los endpoints automáticamente
add_prometheus_middleware(app, agent_type="sales", model_name="gemini-2.0")

# Opción 2: Registro manual
from app.observability import (
    record_classification_latency,
    record_deal_probability,
    set_model_accuracy,
    set_error_rate,
    record_api_call,
)

record_classification_latency(145.5, agent_type="sales", model_name="gemini-2.0")
record_deal_probability(0.78, agent_type="sales", model_name="gemini-2.0")
set_model_accuracy(0.92, agent_type="sales", model_name="gemini-2.0")
set_error_rate(0.05, agent_type="sales", model_name="gemini-2.0")
record_api_call(agent_type="sales", model_name="gemini-2.0")

# Opción 3: Decorador
@measure_latency(agent_type="sales", model_name="gemini-2.0", endpoint="/classify")
def classify_lead(lead):
    return process(lead)

# Opción 4: Batch
from app.observability import record_batch
record_batch([
    {"type": "latency", "value": 145.5, "agent_type": "sales", ...},
    {"type": "deal_probability", "value": 0.78, "agent_type": "sales", ...},
])

ENDPOINT PROMETHEUS:
────────────────────

GET /metrics

Retorna métricas en formato Prometheus text-based (OpenMetrics):

```
# HELP agent_classification_latency_ms Latencia de clasificación...
# TYPE agent_classification_latency_ms histogram
agent_classification_latency_ms_bucket{agent_type="sales",...,le="10"} 0.0
agent_classification_latency_ms_bucket{agent_type="sales",...,le="25"} 1.0
agent_classification_latency_ms_bucket{agent_type="sales",...,le="+Inf"} 1.0
agent_classification_latency_ms_count{agent_type="sales",...} 1.0
agent_classification_latency_ms_sum{agent_type="sales",...} 145.5

# HELP model_inference_accuracy Exactitud del modelo...
# TYPE model_inference_accuracy gauge
model_inference_accuracy{agent_type="sales",...} 0.92

# HELP error_rate Tasa de error actual...
# TYPE error_rate gauge
error_rate{agent_type="sales",...} 0.05

# HELP api_call_count Número total de llamadas API
# TYPE api_call_count counter
api_call_count_total{agent_type="sales",...} 5.0

# HELP deal_probability_distribution Distribución de probabilidades...
# TYPE deal_probability_distribution histogram
deal_probability_distribution_bucket{...,le="0.3"} 2.0
deal_probability_distribution_bucket{...,le="0.5"} 5.0
deal_probability_distribution_bucket{...,le="0.8"} 8.0
deal_probability_distribution_bucket{...,le="+Inf"} 10.0
deal_probability_distribution_count{...} 10.0
deal_probability_distribution_sum{...} 6.8
```
