CORE FEATURES
=============

1. Intent Detection
   ├─ BUDGET_ASK     → keywords: presupuesto, precio, dinero, costo, tarifa
   ├─ OBJECTION      → keywords: caro, competencia, objeción, demasiado
   ├─ TIMELINE       → keywords: cuando, cuándo, urgente, necesito, demo
   ├─ NEGOTIATION    → keywords: descuento, oferta, promoción, negociar
   ├─ STRATEGY       → keywords: comparar, análisis, roi, impacto
   └─ UNKNOWN        → default (no keyword match)

   Performance: ~5-10ms per detection (regex pattern matching)
   Confidence: keyword match = 0.85 + boost (0.15) = 1.0, no match = 0.3
   Threshold: below 0.6 → UNKNOWN intent

2. Pipeline Routing
   ├─ SIMPLE INTENTS (BUDGET_ASK, TIMELINE, UNKNOWN)
   │  ├─ 70% (default) → Groq (fast, cost-effective)
   │  └─ 30% (default) → Gemini (testing, gradual rollout)
   │
   ├─ COMPLEX INTENTS (OBJECTION, NEGOTIATION, STRATEGY)
   │  └─ 100% → Gemini (advanced reasoning)
   │
   └─ DETERMINISTIC PER USER
      └─ hash(user_id) % 100 → consistent routing in traffic bucket

3. Rate-Limit Fallback
   - Primary pipeline selected (e.g., Groq)
   - If rate-limited: try fallback (Gemini)
   - If both rate-limited: raise ValueError
   - Status updated via: set_rate_limit_status(Pipeline.GROQ, is_limited=True)
   - Context override: {"groq_rate_limited": True}

4. Metrics System
   ├─ RouteMetrics: timestamp, intent, confidence, pipeline, reason, latency
   ├─ Buffer Storage: last N metrics (default 1000, circular)
   ├─ Statistics API: router.get_stats() → distribution, latency, fallback rate
   ├─ Filtering API: router.get_metrics(intent_filter=Intent.BUDGET_ASK)
   └─ Latency Alerts: log WARNING if latency > 500ms (configurable)

5. Configuration
   ├─ use_hybrid_routing: True (enable Groq/Gemini split)
   ├─ groq_traffic_percentage: 70 (70% Groq, 30% Gemini)
   ├─ fallback_to_gemini: True (fallback on rate-limit)
   ├─ enable_metrics: True (track routing decisions)
   ├─ fallback_latency_threshold_ms: 500 (alert threshold)
   ├─ min_intent_confidence: 0.6 (below this → UNKNOWN)
   ├─ keyword_confidence_boost: 0.15 (+15% if keyword found)
   ├─ metrics_buffer_size: 1000 (store last N metrics)
   └─ enable_latency_alerts: True (log latency warnings)

TROUBLESHOOTING
===============

Problem: Routes always go to Groq
Cause: use_hybrid_routing=False
Fix: config = RouterConfig(use_hybrid_routing=True)

Problem: No metrics recorded
Cause: enable_metrics=False
Fix: config = RouterConfig(enable_metrics=True)

Problem: Latency > 500ms
Cause: System overload or regex performance issue
Fix: Increase fallback_latency_threshold_ms or disable alerts

Problem: Rate-limit fallback not working
Cause: set_rate_limit_status() not called after 429 errors
Fix: Call router.set_rate_limit_status(Pipeline.GROQ, True) on error

Problem: Too many unknown intents
Cause: min_intent_confidence threshold too high
Fix: Lower min_intent_confidence (e.g., 0.5 instead of 0.6)
