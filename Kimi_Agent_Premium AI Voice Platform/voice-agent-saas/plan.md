# Plan Maestro: Voice Agent OS - Plataforma SaaS Premium

## Visión
Construir una web SaaS de nivel premium para "Voice Agent OS" — El Sistema Operativo de los Agentes de Voz IA.
6 páginas completas, diseño comparable a Huly.io/Stripe/Linear, posicionamiento de líder mundial.

## Fases de Ejecución

### Fase 1: Investigación & Análisis de Referencias
- Analizar Huly.io en profundidad (estética, animaciones, componentes, tipografía, colores)
- Analizar sitios de referencia: Stripe, Linear, Notion, OpenAI
- Extraer patrones de diseño premium SaaS 2026
- Documentar hallazgos en research-brief.md

### Fase 2: Diseño Visual & Sistema de Diseño
- Skill: vibecoding-webapp-swarm (cargar SKILL.md)
- Crear design.md con:
  - Paleta de colores oscura premium
  - Tipografía
  - Espaciado
  - Componentes
  - Animaciones
  - Gradientes
  - Sombras
- Definir sistema de diseño completo inspirado en Huly pero original

### Fase 3: Arquitectura de Contenidos & Copywriting
- Sitemap completo
- Wireframes textuales de las 6 páginas
- Copy completo para cada sección (siguiendo principios de Ogilvy, Schwartz, Wiebe)
- SEO: titles, meta descriptions, H1-H3, keywords, estrategia de enlazado

### Fase 4: Desarrollo Web - Página Principal
- Skill: vibecoding-webapp-swarm
- Construir página principal completa con todas las secciones:
  - Hero potente
  - Problema/Solución
  - Marketplace de Agentes
  - Cómo funciona
  - Beneficios
  - ROI
  - Características
  - Comparativa
  - Testimonios
  - FAQ
  - CTA final
  - Footer premium

### Fase 5: Desarrollo Web - Páginas de Agentes (5 páginas)
- SDR Agent
- Closer Agent
- Follow-Up Agent
- Appointment Agent
- Receptionist Agent
- Cada una: Hero, Problema, Cómo funciona, Resultados, ROI, Casos, FAQ, CTA

### Fase 6: Animaciones & Microinteracciones
- Animaciones de entrada
- Hover effects premium
- Scroll animations
- Gradient animations
- Particle effects sutiles
- Transiciones entre secciones

### Fase 7: Optimización & Despliegue
- Revisión de calidad visual
- Verificación de responsive
- Optimización de performance
- Deploy
