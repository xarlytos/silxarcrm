# VoiceAgent OS v2 — Plan de Mejoras Masivas

## Objetivo: Hacer la web MUCHO más atractiva, humana, y visual

## Problemas a Resolver
1. **Se siente "IA"** → Añadir personas reales, escenarios auténticos, fotografía humana
2. **Pocas imágenes** → 20+ nuevas imágenes de alta calidad
3. **Diseño oscuro monótono** → Añadir secciones con fondos variados, colores cálidos
4. **Falta storytelling visual** → Añadir narrativa con imágenes que conecten emocionalmente
5. **Falta credibilidad visual** → Fotos de equipo, oficinas, clientes reales

## Estrategia Visual
- **Más personas**: Fotos de personas diversas, expresiones auténticas
- **Escenarios reales**: Oficinas, llamadas, reuniones, espacios de trabajo
- **Testimonios con fotos reales**: Headshots profesionales variados
- **Equipo humano**: Mostrar que hay humanos detrás del producto
- **Fotografía de producto**: Mockups más realistas y contextuales
- **Colores cálidos**: Acentos ocasionales de naranja/dorado para calidez
- **Texturas**: Elementos orgánicos, menos "digital perfecto"

## Mejoras de Diseño
- Más variedad en fondos (no todo oscuro puro)
- Añadir gradientes cálidos (naranja/dorado) ocasionalmente
- Más espacio visual, menos texto denso
- Imágenes grandes y dominantes
- Efectos de parallax sutiles
- Partículas/flotantes decorativos
- Mejor contraste visual entre secciones
