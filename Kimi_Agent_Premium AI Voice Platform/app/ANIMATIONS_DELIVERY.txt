QUICK START INSTRUCTIONS
================================================================================

1. IMPORT A VARIANT:
   import { fadeInUp } from '@/hooks/useAnimations'
   <motion.div variants={fadeInUp}>Content</motion.div>

2. USE A HOOK:
   const { ref, controls } = useScrollTrigger()
   <motion.div ref={ref} animate={controls}>Scrolls into view</motion.div>

3. USE A PRESET:
   import { heroHeadline } from '@/hooks/animationPresets'
   <motion.h1 variants={heroHeadline}>Title</motion.h1>

4. STAGGER ITEMS:
   <motion.div variants={containerVariants(0.1)}>
     {items.map((item, i) => (
       <motion.div key={i} variants={itemVariants(fadeInUp)}>{item}</motion.div>
     ))}
   </motion.div>
