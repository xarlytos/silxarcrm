================================================================================
API ENDPOINTS (9 ENDPOINTS)
================================================================================

PUBLIC ENDPOINTS (no authentication)

POST /api/memory-guardian/cache
  Cache a conversation turn (automatic or manual)
  Returns: Updated prospect memory with extracted info

GET /api/memory-guardian/memory/:leadId
  Get complete cached memory for a lead
  Returns: Full conversation history and extracted data

POST /api/memory-guardian/detect-repetition
  Detect if prospect is repeating information
  Returns: Repetition status, field, confidence, empathy response

GET /api/memory-guardian/alerts/:leadId
  Get alerts based on memory analysis
  Returns: List of alerts (repetition, opportunity, risk)

GET /api/memory-guardian/summary/:leadId
  Get formatted memory summary for display
  Returns: Human-readable summary + raw memory data

GET /api/memory-guardian/conversation-excerpt/:leadId
  Get recent conversation turns (default: last 5)
  Returns: Recent turns with timestamps

GET /api/memory-guardian/health
  Health check endpoint
  Returns: Service status

ADMIN ENDPOINTS (authentication required)

DELETE /api/memory-guardian/memory/:leadId
  Clear/reset memory for a prospect
  Returns: Confirmation

GET /api/memory-guardian/health
  Detailed health status
  Returns: Service metrics
